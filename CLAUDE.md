# Moneysleep «Живой словарь» — правила проекта

- Владелец продукта: Герхард. Общение и отчёты — по-русски, коротко.
- Задачи лежат в docs/tickets/ (01 — приложение, 02 — языковые пакеты). Делать по порядку.
- UI и дизайн: сначала скриншот на iPad на согласование, финальный код — только после одобрения Герхарда.
- Ребёнок 3+ не читает: всё через картинку, голос и мордашки (улыбка / грусть), не через текст и не через красный/зелёный цвет.
- Изучаемый язык сейчас английский (американский). Перевода в приложении нет. Родительская часть — без слов (цифры, иконки, картинки).
- Звук только mp3/m4a (iPad Safari). Озвучка готовая, лежит в assets/audio/<lang>/, имя файла = id. ElevenLabs из кода не вызывать.
- Без сервера для данных ребёнка, без аналитики и трекинга; прогресс только в IndexedDB на устройстве.
- Секреты и ключи — только в .env, никогда в коде и в чате.
