# Озвучка голосом Mo (`npm run voice`)

Офлайн-инструмент для ассетов. Приложение ElevenLabs не вызывает — только этот скрипт, только при генерации файлов.

- Голос Mo `VZecfgmpcTkkHNOiQKWr`, модель `eleven_multilingual_v2`, `mp3_44100_128` — для всех языков (`config.json`).
- Берёт из `content/packs/<lang>/pack.json` записи, у которых нет файла `assets/audio/<lang>/<id>.mp3` (и есть текст).
- Ключа в коде, `.env` и логах нет. Прокси среды сам подставляет `xi-api-key` для `api.elevenlabs.io` («Сетевой секрет» среды Default, путь `/v1/text-to-speech/`); домен `api.elevenlabs.io` должен быть в «Доступ к сети».

```bash
npm run voice                                    # сухой прогон всех языков: строки, знаки, кредиты (ничего не тратит)
npm run voice -- --lang en-US,es-419             # сухой прогон выбранных языков
npm run voice -- --lang en-US,es-419 --yes       # генерация (стоп, если знаков больше --max-chars, по умолчанию 2500)
npm run voice -- --lang en-US --only kitchen.cup --yes     # одна строка (проверка связи)
npm run voice -- --lang en-US --force mo.thank_you --yes   # перезаписать эти id, даже если файл есть
```

После генерации каждого файла: тишина по краям обрезается до ~80 мс, громкость — около −16 LUFS (усиление + лимитер пиков −1,5 дБ, ffmpeg).
Потом собирается прослушка `docs/audio-preview/<lang>-<комната>.mp3` (всё, что озвучено скриптом, в порядке pack.json, пауза 0,7 с) и запускается валидатор.

Журнал `tools/voice/log/<lang>.json`: какой текст, каким голосом и моделью озвучен, громкость, дата. По нему видно, что пересоздать после правки текста (`--force <id>`).
