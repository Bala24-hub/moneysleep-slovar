БИЛЕТ: Moneysleep «Живой словарь» — языковые пакеты + родительская часть без слов + интервальное повторение

Контекст
В приложении нет перевода: ребёнок видит картинку и слышит слово на изучаемом языке. Поэтому новый изучаемый язык = новые данные (тексты + озвучка), а не новый код. Сейчас всё на английском (американский). Следующие языки: немецкий (de-DE) и испанский латиноамериканский (es-419). Решение Герхарда от 16.11.2026: родительская часть делается БЕЗ СЛОВ (цифры, иконки, картинки), переводим только рекламу и лендинг.

1. Языковые пакеты (контент как данные)
- Структура: content/packs/<lang>/pack.json + audio/<lang>/<id>.mp3 (для iPad Safari только mp3 или m4a, НЕ ogg/opus).
- У каждого слова постоянный id (например kitchen.fridge). Сцена и координаты зоны нажатия общие для всех языков, картинки те же.
- По языку у слова хранятся: text (в немецком и испанском ВСЕГДА с артиклем: der Kühlschrank, el refrigerador), audio, форма для рамки «это …» (EN: a cup, DE: die Tasse, ES: una taza) с отдельным аудио. Поправка Герхарда 16.11.2026: в испанском форма «это …» — с неопределённым артиклем: «Esto no es una taza. Esto es un tenedor.»
- Фразы этапов «Проверка» и «Фразы» хранятся ЦЕЛИКОМ, со своим аудио на каждое слово: «Show me the chair!», «Where's the kitchen towel?», «I want the cup!», DE «Zeig mir den Stuhl!» (артикль меняется по падежу), ES «¡Muéstrame la silla!». Склейка из кусков запрещена, кроме ответа на ошибку: [Try again.] [This is not] [слово.форма «это»] [This is] [слово.форма «это»].
- Изучаемый язык выбирается флажком, без слов.
- Подписи на картинках (отключаемые) показываются на изучаемом языке.
- Новый язык = новая папка, код не трогаем. Скрипт-валидатор: у каждого слова и фразы в каждом пакете есть текст и аудио; если чего-то нет, выдаёт список пропусков.
- Как продаём языки (каждый отдельно или все вместе) — решит Герхард. В коде заложить доступ по языкам (entitlements), чтобы работали оба варианта.

- Лексика кухни (английский, американский): fridge, frying pan (висит над плитой), kitchen towel (на ручке духовки), chair, table, cup, plate, spoon, fork, bowl. Слово dishcloth — отдельным предметом позже. Сковородка в испанском — только la sartén (16.11.2026). В этапе «Проверка» два вида вопросов: «Show me the X!» и «Where's the X?».

2. Родительская часть без слов (макет одобрен Герхардом 16.11.2026)
- Вход для родителей без слов: подержать кнопку 3 секунды (кольцо заполняется) или нажать цифры, показанные точками.
- Экран отчёта, только цифры и иконки, ни одной текстовой строки:
  - сверху Mo и 7 кружков — дни недели, заполнен = ребёнок занимался;
  - кольцо «выучено / всего» (47 / 130) с иконкой карточек;
  - рядом зелёная стрелка вверх и «+12» — прирост за неделю;
  - три плитки: огонёк + дни подряд; галочка + % верных ответов; часы + минуты в день (12′);
  - комнаты: иконка комнаты (сковородка, ванна, кровать, горка…) + полоса прогресса + «13/13»;
  - «Повторить сегодня»: иконка повтора + плитки-картинки слов; на каждой кнопка звука, нажатие проигрывает слово на изучаемом языке;
  - внизу маленькие иконки замка и телефона = данные хранятся только на устройстве.
- Данные только локально (IndexedDB), без сервера, аналитики и трекинга (DSGVO, дети).
- Перед окончательной вёрсткой прислать скриншот экрана на iPad для согласования (правило Герхарда: сначала скриншот, потом финальный код).

3. Интервальное повторение 1 · 3 · 7 дней (обещано в рекламе, к запуску обязательно)
- Слово считается выученным после верного ответа на этапе «Проверка». Тогда оно становится «к повторению» через 1 день, потом через 3, потом через 7.
- Слова «к повторению» выходят в «Повторить сегодня» и в первую очередь попадают в «Проверку».
- Ошибка сбрасывает интервал на 1 день.

4. Обещания из рекламы, которые к запуску должны быть правдой
10 комнат, 130 слов; Mo просит показать предмет (проверка); фразы; повторение 1·3·7; отчёт для родителей; все обновления бесплатно (новые комнаты, до 30); работа офлайн после установки PWA (service worker кэширует пакет выбранного языка).
