БИЛЕТ 4: пробная аудиодорожка «Прогулка с Mo» (кухня, en-US)

Делать после того, как пройдёт озвучка кухни (ждём ключ ElevenLabs).

- Цель: человек включил и слушает на прогулке, экран заблокирован.
- Собрать из уже готовых mp3 кухни одну дорожку на 5–7 минут: слово → пауза 2 с для повтора → слово ещё раз → фраза с этим словом («Show me the cup!», «I want the cup!») → пауза 3 с. Порядок как в pack.json. Новых генераций по возможности не делать; если нужны 2–3 связки Mo (приветствие, «Now you!», прощание) — добавить их в сухой прогон и показать число знаков.
- В приложении: простая страница с обычным <audio> и Media Session API (название, обложка с Mo, пауза/перемотка на экране блокировки). Никакого Web Audio для воспроизведения — оно глохнет при блокировке.
- mp3 положить и в docs/audio-preview/walk-kitchen-en-US.mp3 (для пересылки Герхарду).
- Экран плеера — сначала скриншот на согласование. Проверку на заблокированном iPhone сделает Герхард, когда будет хостинг.
