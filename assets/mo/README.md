# Mo

- `mo.svg` — Mo (viewBox -4 -8 182 194): синий круглый, белый колпак с красным помпоном, золотая «M» на отвороте.
- `mo_talk.svg` — тот же Mo с говорящим ртом:
  - `#mC` — улыбка (рот закрыт);
  - `#mO` — группа «открытый рот» (по умолчанию opacity 0): `#mOe` — тёмная форма рта, `#mOc` — та же форма как clipPath, `#mOt` — язычок.

Как в рекламном ролике: каждые ~33 мс берём громкость голоса Mo (AnalyserNode, полоса 250–3000 Гц), переводим в `o` от 0 до 1 (быстро открывается, мягче закрывается). Если `o < 0.08` — показываем улыбку, иначе открытый рот:

```js
const h = 3.4 + o * 9, w = 6.4 + o * 1.8, y0 = 125.2, x0 = 82 - w, x1 = 82 + w;
const d = `M${x0} ${y0} Q82 ${y0 + 2.2} ${x1} ${y0} C${x1} ${y0 + h * .7} ${82 + w * .55} ${y0 + h} 82 ${y0 + h} C${82 - w * .55} ${y0 + h} ${x0} ${y0 + h * .7} ${x0} ${y0}Z`;
mOe.setAttribute('d', d); mOc.setAttribute('d', d);
mOt.setAttribute('rx', w * .62); mOt.setAttribute('ry', h * .32); mOt.setAttribute('cy', y0 + h * .92);
```
